# JERONIX design guidelines (v0.2)

All values come from [tokens/tokens.json](tokens/tokens.json) (tokens
0.2.0). Code and artwork reference token names, never raw values. Derived
assets (the shell stylesheet, wallpapers and icon PNGs) are generated by
`scripts/jeronix_design.py` and never edited by hand.

## Character

Calm, premium and handcrafted. Charcoal surfaces, muted sage accents,
generous spacing, rounded shapes and restrained motion.

## Color

- Both dark and light modes define the same roles. Tests enforce this.
  - Surfaces: `surface` (base), `surface-raised` (popovers, dialogs, search),
    `surface-overlay` (controls, cards inside popovers).
  - Text: `text` (primary), `text-secondary` (supporting text such as message
    bodies), `text-muted` (hints, captions, placeholders).
  - `panel` and `on-panel`: the top bar stays charcoal in **both** modes. It
    is the most constant brand surface.
  - `accent`, `accent-strong` and `on-accent` for "on" and selected states;
    `focus-ring` for keyboard focus; and the status colors `success`,
    `warning` and `danger`.
- Interaction states come from `interaction`: hover, pressed and disabled lay
  the text color over the surface at a fixed opacity, and selection uses the
  accent at `selected-opacity`. Opaque results (`control-hover`) are
  computed so their contrast can be tested.
- Contrast minimums (WCAG 2.x) are listed in `contrast.pairs` and checked
  for both modes: 4.5:1 for text and 3:1 for focus rings and non-text UI.
  `contrast.brand-pairs` covers the logo on its backgrounds.
- Never use the accent as the only signal of state. Pair it with an icon,
  label or shape.

## Typography

Ubuntu Sans for UI text and Ubuntu Sans Mono for code. Both ship with
Ubuntu 26.04, so no fonts are bundled. Sizes are multiples of
`base-size-pt` taken from `typography.scale`. The shell theme writes them
as `em`, so the user's font and text-scaling settings apply to all of them.

## Shape, spacing, components

- Spacing uses only the named steps in `spacing-px` (a 4 px grid).
- Radius: `small` for inline controls, `medium` for menu items, list rows
  and inner cards, `large` for popovers, dialogs, notifications, tiles and
  the dock, and `pill` for toggles, the search entry and panel buttons.
- `component` holds fixed dimensions: border and focus-ring widths, the
  minimum control height, and popover and search widths.
- Use the two shadow levels only: `raised` and `overlay`. Light mode uses
  them at half strength.

## Motion

Use 120 ms for feedback, 200 ms for transitions and 320 ms for large
surfaces, with ease-out-quad easing. When the system's reduced-motion
setting (`org.gnome.desktop.interface enable-animations`) is off, use 0 ms.
GNOME Shell applies that automatically to the theme's `transition-duration`.

## Keyboard and accessibility

- Every interactive element must be reachable and operable from the
  keyboard, with a visible `focus-ring`. On accent-filled controls the ring
  uses `on-accent`.
- Every control needs an accessible name. Shell toggles inherit theirs from
  `title`.
- Icon-only buttons need tooltips.

## Logo and imagery

The mark is a drawn J: a stem that hooks back upward, plus an offset "seed"
dot in place of the crossbar, on a charcoal tile. Variants, sizes and uses
are listed in [icons/README.md](icons/README.md). Brand colors come from
the `brand` tokens.

The wallpapers repeat the J's hook as nested contour lines rising off the
top edge, with the seed placed as in the mark. Their colors are chosen by
name in `wallpaper` in the tokens.
